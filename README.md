# Sysadmin Automation Scripts

A growing collection of Python, PowerShell, Bash, and Azure automation scripts focused on system administration, networking, cloud administration, and security.

This repository serves as a hands-on collection of tools and scripts created while building practical experience with Linux, Windows administration, networking, and Microsoft Azure.

## Categories

### Python
Python scripts for networking, troubleshooting, automation, and system administration.

### PowerShell
PowerShell scripts for Windows administration, Active Directory, Azure, and automation.

### Bash
Linux administration and automation scripts.

### Azure
Scripts focused on Microsoft Azure administration and cloud automation.

- TCP Port Scanner

More scripts will be added as the repository grows.

## Purpose

The goal of this repository is to build practical automation tools that can assist with common system administration, networking, cloud, and troubleshooting tasks.

The repository will continue to expand as I develop additional scripts and gain more experience with system administration and Azure environments.
